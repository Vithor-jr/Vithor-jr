##  Research & Teaching

<details open>
<summary><b>PIBIC — Machine learning for drug discovery</b></summary>
<br>

My PIBIC project focuses on predicting **pIC50** (compound potency) against two therapeutic targets, **BACE1** and **LRRK2**, using an **ensemble/stacking of frozen molecular representations** (embeddings and fingerprints) paired with multiple regressors (e.g. SVR, Tanimoto-SVR).

- **Methodology:** Optuna hyperparameter search with scaffold-grouped cross-validation (GroupKFold), ablations using only out-of-fold predictions from the training set, a single held-out test set, and nested CV.
- **Data:** curated datasets built from ChEMBL, PubChem, MoleculeNet and BindingDB, standardized with RDKit and deduplicated by InChIKey.
- **Goal:** publish the results as a paper.

</details>

<details open>
<summary><b>PIC-Jr (OBMEP) — Teaching</b></summary>
<br>

Since 2025, I have been a **teacher in the PIC-Jr** (Programa de Iniciação Científica Júnior) of **OBMEP**, helping students from public schools develop their mathematical skills and prepare for olympiad-style problem solving.

</details>
